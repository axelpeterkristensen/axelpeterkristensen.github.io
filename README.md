# axelpeterkristensen

Personal website, built with [Quarto](https://quarto.org) and published to GitHub Pages via GitHub Actions.

- Edit `index.qmd`, `research.qmd`, `cv.qmd`. Push to `main` and the site rebuilds.
- Replace `images/axel.jpg` with a portrait (roughly 4:5, at least 640 px wide).
- Set `site-url` in `_quarto.yml` to the real URL so the sitemap is correct.
- Preview locally with `quarto preview`.
